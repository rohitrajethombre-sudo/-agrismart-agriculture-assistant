# Contributing to AgriSmart

Thank you for considering a contribution.

## Ways to contribute

- Report a reproducible bug or calculation issue.
- Improve Marathi or English wording.
- Suggest a useful farmer-focused feature.
- Improve accessibility, mobile layout or documentation.
- Submit a code change with a clear explanation.

## Before opening an issue

1. Search existing issues to avoid duplicates.
2. Describe what you expected and what happened.
3. For calculation issues, include sample inputs and the expected result.
4. Remove personal information and private farm records.

## Pull requests

- Keep changes focused.
- Explain why the change is useful.
- Test the affected calculator in a browser.
- Do not add unsupported pesticide or fertilizer recommendations.
- Be respectful and constructive.

## Agricultural safety

Do not present unverified application rates as recommendations. Any agronomic content should cite reliable, locally relevant sources and explain its scope and limitations.
