# AgriSmart — Agriculture Assistant

AgriSmart is a small, community-built open-source project providing practical agriculture calculators and introductory learning resources. The first version focuses on farmers and agriculture learners who prefer Marathi or English.

## Features

- Fertilizer quantity calculator using a user-entered recommended rate
- Spray dilution calculator using a product-label dose entered by the user
- Acre, hectare and guntha converter
- Introductory N, P, K and S nutrient learning notes
- Marathi and English interface
- Responsive layout for mobile and desktop

## Run locally

No installation or programming tools are required.

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Select **Settings** → **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Save and wait for GitHub Pages to publish the site.

## Safety and scope

AgriSmart is an educational tool, not a substitute for local agronomic advice. It does not recommend pesticide or fertilizer application rates. Users must enter rates from valid product labels, soil-test recommendations, local regulations or qualified advisers. Always verify units and calculations before use. Nutrient symptoms can overlap and should not be used as a stand-alone diagnosis.
